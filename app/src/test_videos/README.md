# User Test Videos / 用户测试视频

[English](#en) | [中文](#zh-cn)

## English

### Authorized test footage

This folder is `app/src/test_videos/` in the extracted package. From the extracted root, run `cd app` before using the application; enter test paths such as `src/test_videos/sample.mp4` relative to `app/`.

Place MP4/MOV/AVI material here only if you have permission to use it. Videos in this directory are excluded from Git and release archives by default. Example filenames are placeholders; no real-worker footage is included. Test input cannot activate the buzzer.

## 中文

本目录位于解压包的 `app/src/test_videos/`。先从解压根目录执行 `cd app` 再使用程序；测试路径以 `app/` 为基准填写，例如 `src/test_videos/sample.mp4`。

放入自己有权使用的 MP4/MOV/AVI 测试素材。此目录的视频默认不进入 Git/Release。示例视频路径只是占位，不包含真实员工视频。测试不能驱动蜂鸣器。
