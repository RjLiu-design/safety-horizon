## English

These files document the package contents. To install the application, download the complete platform ZIP from [GitHub Releases](https://github.com/RjLiu-design/safety-horizon/releases/tag/v0.3.0), not this folder alone.

| File | Purpose |
|---|---|
| [Release notes](RELEASE_NOTES.md#en) | Version features and installation guidance |
| [File index](FILE_INDEX.md) | Description of each packaged file |
| [Build manifest](BUILD_MANIFEST.json) | Version, license and package allowlist |
| [SHA256SUMS](SHA256SUMS) | Internal checksums; file paths are relative to the package root |
| [Source provenance](SOURCE_PROVENANCE.json) | Original source hashes for traceability |
| [Third-party notices](THIRD_PARTY_NOTICES.md#en) | Dependency and model licensing |

The separate `SHA256SUMS` attachment on the release page checks the two ZIP downloads. It is not the same as the internal `release/SHA256SUMS` file. Both are generated during packaging.

## 中文

本目录说明发布包的组成。安装程序请在 [GitHub Releases](https://github.com/RjLiu-design/safety-horizon/releases/tag/v0.3.0) 下载完整平台 ZIP，不要只下载此文件夹。

| 文件 | 用途 |
|---|---|
| [版本说明](RELEASE_NOTES.md#zh-cn) | 本版内容与安装说明 |
| [文件索引](FILE_INDEX.md) | 每个发布文件的用途 |
| [构建清单](BUILD_MANIFEST.json) | 版本、许可与打包白名单 |
| [SHA256SUMS](SHA256SUMS) | 包内文件校验值，路径相对于解压根目录 |
| [源码溯源](SOURCE_PROVENANCE.json) | 原始源码哈希，便于追溯 |
| [第三方声明](THIRD_PARTY_NOTICES.md#zh-cn) | 依赖与模型许可 |

Release 页面独立的 `SHA256SUMS` 附件用于校验两个 ZIP，与包内的 `release/SHA256SUMS` 不同。两份清单均由打包脚本生成。
